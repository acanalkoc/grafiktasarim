# Scientific Graph Studio 7.2.0

- v7.1 denetim düzeltmeleri ve modüler uygulama kodu GitHub sürümüne taşındı.
- Birden fazla veri tablosu, A–D panellere atama, çizgi/sütun ve bilimsel analiz akışları.
- Kaynak bağlantıları, geri al, tablo düzenleme ve yayın önizlemesi iyileştirmeleri.
- Windows x64 kurulum dosyası ve taşınabilir ZIP için test kapılı yayın hattı.
- Otomatik kayıtlar kurulum klasörü yerine kullanıcı veri klasörüne yazılır.
- Windows grafiği panoya kopyalama gerçek PNG + DIB biçimleriyle çalışır.
- EXE dosya/ürün sürümü, bağımlılık bildirimleri ve SHA256 doğrulaması.

Bu sürümün Windows ikilileri imzasızdır. Erişilebilirlik, çok büyük veri kümelerinde
iptal/ilerleme ve farklı ekran ölçeklerinin insan kabulü konularında
[AUDIT_V71.md](AUDIT_V71.md) sınırlamaları geçerlidir.
